# Log de estudos em Java - 26/06/2026

## O que fiz hoje

Consolidei a entrega atual do `Nível 1` em Java no repositório principal com um mini-projeto simples de terminal para registro de produtos.

Também revisei a documentação com base nos PDFs da Sistemium para manter o PR dentro do escopo certo da etapa.

## Base que usei para chegar neste projeto

Antes do mini-projeto, eu já vinha praticando em Java:

- leitura de dados com `Scanner`;
- uso de `ArrayList`;
- arrays;
- `for` e `while`;
- condicionais;
- classes em nível inicial.

Esses exercícios de lógica serviram como base do meu nível atual na linguagem.

## O que pratiquei no mini-projeto

- organização do código em arquivos separados;
- criação da classe `Produto`;
- cadastro em memória com `ArrayList`;
- validação de nome e preço;
- tratamento de erro com `IllegalArgumentException`;
- menu de terminal com fluxo simples;
- fechamento correto do `Scanner`;
- criação de um teste básico sem framework externo.

## Problemas e cuidados desta revisão

- a branch atual estava documentada como `Nível 0`, mesmo sendo uma branch de `Nível 1`;
- o foco anterior do repositório estava muito puxado para Python, e não para a entrega atual em Java;
- o mini-projeto Java da área de trabalho tinha roteiro manual, mas ainda precisava de uma evidência simples de teste básico executável no próprio projeto;
- foi necessário manter o projeto simples para não fugir do nível atual da trilha.

## Como ficou a entrega

- mini-projeto em `java/mini-projetos/01-sistema-registro-produtos-java/`;
- README com objetivo, escopo, compilação, execução e testes;
- checklist simples alinhado aos documentos da Sistemium;
- roteiro de teste manual;
- log de estudos atualizado para sustentar a abertura do PR.

## O que aprendi hoje

Aprendi que, para uma entrega inicial em Java ficar coerente com a trilha, não basta funcionar. Ela também precisa mostrar claramente:

- qual era minha base real de estudo;
- o que o mini-projeto prova;
- que eu revisei detalhes simples de lógica e de uso de recursos;
- que o projeto continua pequeno o bastante para ser explicável por alguém em início de linguagem.
