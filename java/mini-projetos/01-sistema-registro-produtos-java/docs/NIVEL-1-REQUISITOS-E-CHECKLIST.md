# Nível 1 - Requisitos e checklist da entrega Java

Este documento resume a entrega atual com base nos PDFs da Sistemium:

- `INS-003` - Engenharia, review e evidência

## O que o Nível 1 pede em `INS-007`

Mini-projeto de terminal na stack escolhida com:

- cadastro simples em memória;
- validação de entrada;
- tratamento de erro;
- testes básicos;
- README explicando como rodar.

## Como esta entrega atende ao escopo

Projeto analisado:

- `java/mini-projetos/01-sistema-registro-produtos-java`

O projeto possui:

- cadastro em memória com `ArrayList`;
- classe `Produto`;
- menu de terminal com `Scanner`;
- listagem de produtos;
- busca por nome;
- remoção por nome;
- validação de nome e preço;
- tratamento de erro com `IllegalArgumentException`;
- teste básico em `src/TestesBasicos.java`;
- README com compilação, execução e teste.

## Uso de IA segundo `INS-004`

Nesta entrega, a IA foi usada como apoio de revisão e organização, mas o projeto foi mantido em um nível simples e revisado manualmente para evitar erros de fundamento na lógica e no fluxo de entrada.
