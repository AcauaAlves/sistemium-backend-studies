# Roteiro de Teste Manual

## Cadastro

1. Abrir o programa.
2. Escolher a opção `1`.
3. Digitar um nome válido.
4. Digitar um preço válido.
5. Confirmar que o produto foi adicionado.

## Listagem

1. Escolher a opção `2`.
2. Confirmar que os produtos cadastrados aparecem na tela.

## Busca

1. Escolher a opção `3`.
2. Digitar parte do nome de um produto.
3. Confirmar que o programa encontra o item.

## Remoção

1. Escolher a opção `4`.
2. Digitar parte do nome de um produto existente.
3. Confirmar que ele foi removido.

## Validação de nome

1. Tentar cadastrar produto com nome vazio.
2. Confirmar que o programa mostra erro e continua rodando.

## Validação de preço

1. Tentar cadastrar preço vazio.
2. Tentar cadastrar preço negativo.
3. Tentar cadastrar texto no lugar do preço.
4. Confirmar que o programa mostra erro e continua rodando.
