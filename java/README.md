Neste momento, o foco em Java está nos fundamentos da linguagem e na entrega atual do `Nível 1`.

Os exercícios de lógica foram usados como base para mostrar que eu já consigo trabalhar com:

- loops;
- classes;

Com essa base, a entrega atual avança para um mini-projeto simples de terminal sem sair do escopo de estudo inicial.

## Estrutura
