## Exercicios atuais

- `01-par-ou-impar`
- `02-maior-de-dois-numeros`

## Regra de avaliacao

Cada exercicio desta pasta deve ser apresentado em uma thread separada para avaliacao.

Exemplo:

- thread 1: `01-par-ou-impar`
- thread 2: `02-maior-de-dois-numeros`
- thread 3: `03-calculadora-simples`

Isso permite revisar e pontuar cada exercicio individualmente.
