# Log de Estudos

Esta pasta registra a evolucao do estudo com evidencias por data.

## Objetivo

Manter um historico simples e verificavel do que foi estudado, praticado e corrigido ao longo da trilha Back-End.

## Sugestao de uso

Cada arquivo pode registrar:

- o que foi estudado
- o que foi entendido
- onde houve dificuldade
- que exercicio, projeto ou pratica foi feita
- que evidencia foi gerada
- o que ainda precisa ser revisado
