# Log de estudos - 16/06/2026

## O que fiz hoje

Conclui a entrega tecnica do Nivel 1 da trilha Back-End no repositório com um mini-projeto de terminal em Python para registro de produtos.

O foco foi transformar uma base inicial em uma entrega revisavel, com documentacao, validacao de entrada, tratamento de erro e testes basicos.

## O que pratiquei

- organizacao de codigo em multiplos arquivos
- uso de classe `Produto`
- validacao de nome e preco
- tratamento de erro com excecoes customizadas
- escrita de testes basicos
- revisao manual do codigo gerado e ajustado com apoio de IA

## Problemas encontrados

- a lista inicial misturava objetos `Produto` com dicionarios
- a funcao de listagem quebrava ao acessar os produtos
- o metodo `get_preco()` retornava um atributo inexistente
- os arquivos de teste existiam, mas ainda estavam vazios
- o README do mini-projeto ainda estava com placeholders

## Como corrigi

- padronizei a lista de produtos para usar apenas objetos `Produto`
- corrigi os acessos aos dados usando metodos da classe
- ajustei o metodo `get_preco()`
- escrevi testes basicos para produto, validacao e estrutura da lista
- preenchi o README do mini-projeto com objetivo, requisitos e comandos

## Evidencias geradas

- mini-projeto em `mini-projetos/01-sistema-registro-produtos`
- README atualizado
- testes executados com `python3 -m unittest discover -s tests -p 'test_*.py'`
- execucao manual validada com `python3 src/main.py`
- branch preparada para PR de Nivel 1

## O que aprendi

Aprendi que nao basta o programa "quase funcionar". Para a entrega ficar alinhada com a Sistemium, ela precisa rodar, ter evidencias verificaveis, README executavel e codigo minimamente explicavel.

Tambem ficou mais claro para mim como pequenos bugs de modelagem quebram a aplicacao inteira quando a estrutura de dados nao esta consistente.

## Fechamento da etapa

A entrega tecnica do Nivel 1 ficou concluida no repositório com codigo funcional, testes basicos, README preenchido e evidencias registradas.
